# Terra · wonders-globe

Интерактивный 3D-глобус, подборки необычных мест и личный атлас. Статический сайт без сервера приложения и без сборки JavaScript. Работает на GitHub Pages, в том числе в подпапке репозитория.

## Локальный запуск

Требуется Node.js 22+.

```sh
npm ci
npm run dev
```

Откройте http://127.0.0.1:4173. ES-модули нужно запускать через HTTP, а не двойным кликом по `index.html`.

```sh
npm test             # данные, хранение, кэш и отмена запросов
npm run build        # готовая публикация в dist/
npx playwright install chromium
npm run test:e2e     # браузерные сценарии и проверка рендера
npm run icons        # пересоздать PNG-иконки после изменения assets/logo.svg
```


## Что снижает нагрузку

- `requestRenderMode`: статичный глобус не перерисовывается постоянно; время само по себе не запускает кадр.
- Экономичный режим по умолчанию: разрешение 1× вместо Retina 2×, предел 30 fps во время взаимодействия, без MSAA/FXAA. Кнопка ♧ включает повышенное качество (до 1.5×, 45 fps, FXAA).
- Автовращение выключено при запуске и после возврата к общему виду. При включении работает до 30 обновлений в секунду.
- В скрытой вкладке отключается цикл рендера, вращение и обновление времени. Солнце обновляется раз в минуту в активной вкладке.
- Координаты обновляются по движению камеры, а не каждый кадр. Время — только при открытой карточке, раз в 30 секунд.
- Ограниченный кэш API в памяти: погода на 10 минут, статьи и поиск на час. Устаревшие запросы отменяются.
- Системные шрифты, непрозрачные панели вместо дорогого размытия, статичный маркер без дополнительной геометрии.

WebGL всё ещё использует GPU во время перелётов и приближения. Реальный нагрев зависит от браузера, экрана и устройства.

## Публикация на GitHub Pages

1. Создайте репозиторий `wonders-globe` на GitHub и загрузите файлы проекта (включая `.github`, `.nojekyll` и `package-lock.json`). Основная ветка — `main`.
2. В репозитории: **Settings → Pages → Build and deployment → Source → GitHub Actions**.
3. После push в `main` workflow проверит проект, соберёт `dist/` и опубликует сайт. Можно запустить его вручную через **Actions → Deploy Terra to GitHub Pages → Run workflow**.
4. Адрес: `https://<ваш-логин>.github.io/wonders-globe/`. При другом имени репозитория адрес поменяется; относительные ссылки продолжат работать.

Пример команд из папки проекта после создания пустого репозитория:

```sh
git init -b main
git add .
git commit -m "Launch Terra globe"
git remote add origin https://github.com/<ваш-логин>/wonders-globe.git
git push -u origin main
```

## Небольшая реклама

В `src/config.js` задайте `sponsor.enabled: true`, `title`, `description` и HTTPS `url` партнёра. Появится компактная подписанная карточка под инструментами исследования; на телефоне — сокращённая версия. По умолчанию она скрыта, пока партнёр не задан. Скрипты рекламных сетей и трекеры не загружаются.

Если позже понадобится рекламная сеть, изолируйте её в отдельном модуле и сохраните ограниченный размер блока, чтобы реклама не перекрывала глобус.

**Перед монетизацией:** бесплатный Open-Meteo API рассчитан на некоммерческое использование. Для коммерческого сайта подключите подходящий тариф через собственный прокси и укажите его URL в `services.weatherURL` / `services.geocodingURL`. Платные ключи нельзя хранить в публичном JavaScript. GitHub Pages размещает только статические файлы; прокси размещается отдельно. Условия: https://open-meteo.com/en/terms.

## Данные и ограничения

- CesiumJS 1.121 загружается с CDN; карта и границы — Esri. Атрибуция видна на карте. Для коммерческого использования проверьте условия выбранных картографических сервисов.
- Статьи — Wikipedia (CC BY-SA), фото — с индивидуальной лицензией по ссылке под изображением. Ближайшая статья не обязательно описывает выбранное место точно.
- Погода/часовые пояса — Open-Meteo; поиск — GeoNames через Open-Meteo. Редакционные заметки и подборки — в `src/data/places.js`.
- Сохранённые места, уникальные открытия и настройки — только в `localStorage` этого браузера. При недоступном хранилище сайт продолжает работать, но сохранение не подтверждается.
- «Место дня» меняется по местной календарной дате; повторные посещения одной точки не увеличивают счётчик. «Случайное место» выбирается из редакционных подборок, чтобы посетитель чаще находил историю, а не океан. Любая другая точка доступна на глобусе и через координаты.
- Приложение требует интернет и WebGL; manifest добавляет имя и иконки для ярлыка, офлайн-режим не реализован.
